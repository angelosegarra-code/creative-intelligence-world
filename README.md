# Creative Intelligence Platform

**Every person is creative. The question is how.**

The Creative Intelligence Platform is a Gemini-powered personalized learning system designed to help individuals understand how they naturally imagine, observe, transform, and envision possibilities.

## The InnerCube Framework

The platform uses four complementary dimensions of Creative Intelligence:

- **Dreamer** — imagination and possibility
- **Observer** — awareness and reflection
- **Alchemist** — transformation and experimentation
- **Visionary** — direction and purposeful action

Rather than assigning a fixed personality label, the platform uses these dimensions as a starting point for continued learning and development.

## How the Platform Works

The initial experience follows this automated workflow:

**Stripe → InnerCube Assessment → Make → Google Sheets → Gemini API → Personalized Creative Intelligence Profile → Email Delivery**

Gemini interprets the individual's assessment pattern and generates personalized strengths, growth opportunities, reflections, and practical development suggestions.

## Adaptive Creative Intelligence Companion

The Creative Intelligence Profile is not the end of the experience. It becomes context for an ongoing AI-powered learning relationship.

After receiving a personalized next step, the individual can try the action in the real world and return to the Creative Intelligence Companion.

The Companion then:

1. Identifies the returning individual.
2. Retrieves their existing Creative Intelligence Profile.
3. Receives their new reflection and current goal.
4. Combines the existing profile with this new information.
5. Uses Gemini to interpret what happened.
6. Determines an appropriate creative mode and next action.
7. Delivers new personalized guidance by email.

This creates a recursive learning cycle:

**Profile → Personalized Action → Real-World Experience → Reflection → Gemini Interpretation → Adapted Next Action → Continue**

The guidance therefore changes as the individual acts, reflects, and provides new information.

## Role of Gemini

The Gemini API is the primary production LLM and reasoning layer of the platform.

Gemini is used to:

- Interpret InnerCube assessment patterns
- Generate personalized Creative Intelligence Profiles
- Understand returning-user reflections
- Consider the individual's existing profile and current goal
- Determine an appropriate next creative mode
- Generate an adapted next action

Gemini is therefore used not simply for text generation, but as the intelligence layer within an adaptive learning loop.

## Human-Centered AI

The educational framework and guardrails are human-designed.

The system does not make high-stakes decisions involving employment, admissions, certification, or eligibility. AI autonomy is focused on personalized reflection, learning, creativity, and development.

## Vision

Most AI personalization begins with the question being asked.

Creative Intelligence begins with another question:

**Who is the individual asking it?**

Our goal is to build AI learning experiences that understand both the individual's creative pattern and how that individual changes over time.
